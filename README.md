# Coding Platform DBMS

A MySQL-based DBMS mini-project that manages users, coding problems, contests, and problem submissions using relational database concepts.

## Database Tables

- **Users:** Stores user IDs, usernames, and email addresses.
- **Problems:** Stores problem names, difficulty levels, and points.
- **Contests:** Stores contest names, dates, and total problems.
- **Submissions:** Tracks user submissions, including the problem attempted and submission status.

## Concepts Used

- Relational database design
- Primary and foreign keys
- Referential integrity
- SQL queries using `SELECT`, `WHERE`, and `JOIN`
- Aggregate functions such as `COUNT()` and `SUM()`
- Data grouping using `GROUP BY`
